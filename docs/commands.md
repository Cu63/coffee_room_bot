# Команды бота

## Пользовательские команды

### Счёт и лидерборд

| Команда | Описание |
|---------|----------|
| `/score` | Показать свой текущий счёт |
| `/top` | Топ участников чата |
| `/history` | История последних начислений |

### Мут

Мутить других и снимать мут могут только те, у кого есть право на муты: админы бота (`admin.users`), владелец чата и админы с правом «Блокировка участников». Им бесплатно и без лимитов, а замученный платит штраф `mute.fine` в кассу бота (не больше, чем у него есть): `/unmute` его возвращает, истёкший мут — нет. Титул из `/buyop` и `/op` такого права не даёт, право удалять сообщения — тоже.

| Команда | Описание |
|---------|----------|
| `/mute @user <время>` | Замутить пользователя (или ответом: `/mute <время>`). Повторный мут прибавляется к оставшемуся времени. Форматы: `30`, `30m`, `2h`, `1h30m`. `/amute` — то же самое |
| `/mute random <время>` | Замутить случайного участника с баллами (кроме себя и ботов; вышедшие из чата пропускаются). Без штрафа |
| `/unmute @user` | Снять мут досрочно и вернуть штраф за него (или ответом). Если касса бота успела потратиться, вернёт сколько в ней есть. `/aunmute` — то же самое |
| `/mutelist` | Кто сейчас в муте, сколько осталось и кто выдал |
| `/warn @user причина` | Предупреждение (или ответом). Набрал `warn.limit` за `warn.period_days` дней — автомут на `warn.mute_minutes` минут и штраф `warn.fine`, предупреждения сгорают. Штраф лежит при муте: `/unmute` его возвращает |
| `/unwarn @user` | Снять последнее предупреждение |
| `/unstuck` | Снять ограничения, оставшиеся от старых размутов: раньше размут не возвращал право менять свой тег, и участник оставался ограниченным |

Любому участнику:

| Команда | Описание |
|---------|----------|
| `/selfmute <время>` | Замутить себя |
| `/warns [@user]` | Свои или чужие предупреждения |

### Тег

| Команда | Описание |
|---------|----------|
| `/tag новый_тег` | Установить свой тег (за очки) |
| `/tag @user новый_тег` | Установить тег другому (за очки). Админу, назначенному ботом, меняется титул; владельцу и админам, назначенным не ботом, — нельзя |
| `/tag --clear` | Убрать свой тег |

### Экономика

| Команда | Описание |
|---------|----------|
| `/transfer @user N` | Перевести N очков пользователю |

### Игры

| Команда | Описание |
|---------|----------|
| `/bj <ставка>` | Блекджек: дуэль двух игроков, руки скрыты |
| `/ttt <ставка>` | Исчезающие крестики-нолики: дуэль, после 50 ходов — ничья |
| `/duel @user ttt\|bj <ставка>` | Вызвать конкретного игрока на дуэль |
| `/slots <ставка>` | Однорукий бандит |
| `/dice <ставка> <время>` | Кости: мультиплеер, победитель по наибольшему броску. Пример: `/dice 10 2m` |
| `/giveaway <призы> [время]` | Розыгрыш очков. Пример: `/giveaway 500 100 50 10m` |
| `/mutegiveaway <мут> <кол-во> <сбор>` | Мут-рулетка |

### AI

| Команда | Описание |
|---------|----------|
| `/llm <вопрос>` | Вопрос к языковой модели |
| `/search <запрос>` | Веб-поиск + AI-ответ со ссылками |
| `/think` | Случайная мысль вызвавшего: стиль зависит от его IQ, тема — от последних сообщений чата (`think.messages_count`). Лимит — `think.daily_limit_per_user` в сутки (по умолчанию 2) |
| `/quiz [тема]` | Викторина: вопрос с четырьмя вариантами от LLM, сложность — по IQ вызвавшего. У каждого одна попытка, первый верный ответ получает `quiz.prize` из кассы бота (и +IQ за победу); за `quiz.answer_seconds` никто не ответил — бот показывает ответ |
| `/whosaid` | «Кто это сказал?»: цитата из чата за `whosaid.days` дней и четыре кандидата в авторы. Автор цитаты не отвечает; правила и приз — как у `/quiz` |

|---------|----------|
| `/help` | Интерактивная справка по разделам |
| `/limits` | Показать дневные лимиты |

## Административные команды

Для админов бота из `admin.users` в `configs/config.yaml`.

| Команда | Описание |
|---------|----------|
| `/add @user N` | Начислить N очков |
| `/sub @user N` | Списать N очков |
| `/set @user N` | Установить счёт |
| `/reset @user` | Сбросить счёт в 0 |
| `/status` | Состояние бота: версия (коммит), аптайм, задержка Postgres и Redis, фоновые задачи — последний удачный проход, перезапуски, последняя ошибка за сутки |
| `/op @user` | Назначить модератора |
| `/deop @user` | Снять модератора |
| `/save @user` | Сохранить права администратора |
| `/restore @user` | Восстановить права |
| `/giveaway_end [id]` | Завершить розыгрыш |
| `/mutegiveaway_end [id]` | Завершить мут-рулетку |

## Формат времени

Везде, где нужно указать длительность, поддерживаются форматы:

| Пример | Значение |
|--------|----------|
| `30` | 30 минут |
| `30m` | 30 минут |
| `2h` | 2 часа |
| `1h30m` | 1 час 30 минут |
| `1d` | 1 день |
| `1d2h30m` | 1 день 2 часа 30 минут |
| `45s` | 45 секунд |

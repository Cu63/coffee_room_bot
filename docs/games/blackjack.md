# Блекджек

Дуэль двух игроков в блекджек прямо в чате. Дилера нет: игроки играют друг против друга.

## Команды

```
/bj <ставка>                 — открыть лобби, принять может любой
/duel @игрок bj <ставка>     — вызвать конкретного игрока
```

## Правила

1. Создатель открывает лобби, ставка списывается сразу. Второй игрок принимает вызов кнопкой, его ставка тоже списывается.
2. Каждому раздаётся по две карты из общей колоды, кто ходит первым — решает жребий.
3. Руки скрыты: на столе в чате видны только рубашки. Свои карты игрок смотрит кнопкой **👀 Мои карты** — их видит только он.
4. В свой ход игрок выбирает **🃏 Ещё** (взять карту) или **🛑 Хватит** (остановиться). На 21 игрок останавливается сам.
5. Перебор (больше 21) сопернику не показывается: ход просто переходит.
6. Когда оба закончили, карты вскрываются.

### Стоимость карт

| Карта | Очки |
|-------|------|
| 2–10  | Номинал |
| J, Q, K | 10 |
| A | 11 (или 1, если иначе перебор) |

## Исходы

| Событие | Результат |
|---------|-----------|
| Натуральный блекджек (A + 10 с раздачи) | Игра заканчивается сразу; блекджек бьёт любую другую руку |
| Больше очков без перебора | Победитель забирает банк (2 × ставка) |
| Соперник перебрал | Победитель забирает банк |
| Равные очки или оба перебрали | Ставки возвращаются |

## Таймауты

- Лобби никто не принял за 5 минут — ставка возвращается создателю.
- Начатую игру бросили (10 минут без хода) — обе ставки забирает бот.

## Конфигурация

```yaml
blackjack:
  enabled: true
  min_bet: 1
  max_bet: 100
```

## Технические детали

Состояние игры — JSON в Redis (`bj:duel:<chat>:<game>`). Каждый ход — compare-and-set по
прочитанному снимку (`RedisStore.game_save` / `game_claim`): двойное нажатие не возьмёт ту же
карту дважды и не рассчитает игру второй раз. Ставки и выплаты в журнале операций идут под
меткой `bj:<game_id>`, у дуэли — `duel:<invite_id>`.

Колода и подсчёт очков — `bot/application/blackjack_service.py`, хендлеры —
`bot/presentation/handlers/blackjack/`.

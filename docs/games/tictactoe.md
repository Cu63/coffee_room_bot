# Крестики-нолики

Дуэль в исчезающие крестики-нолики на ставку.

## Команды

```
/ttt <ставка>                — открыть лобби, принять может любой
/duel @игрок ttt <ставка>    — вызвать конкретного игрока
```

## Правила

1. Создатель открывает лобби, ставка списывается сразу. Второй игрок принимает вызов, его ставка тоже списывается.
2. Кто играет крестиками (они ходят первыми), решает жребий.
3. У каждого на поле не больше трёх фигур: четвёртая вытесняет самую старую. Фигура, которая исчезнет следующим ходом, подсвечена.
4. Три в ряд — победа: банк (2 × ставка) забирает победитель.
5. Из-за исчезающих фигур партия может идти бесконечно, поэтому после 50 ходов без победителя — ничья, ставки возвращаются.

## Таймауты

- Лобби никто не принял за 5 минут — ставка возвращается создателю.
- Начатую игру бросили (10 минут без хода) — обе ставки забирает бот.

## Конфигурация

```yaml
tictactoe:
  enabled: true
  min_bet: 1
  max_bet: 100
```

## Технические детали

Состояние игры — JSON в Redis (`ttt:<chat>:<game>`). Каждый ход — compare-and-set по
прочитанному снимку (`RedisStore.game_save` / `game_claim`): из двух одновременных нажатий
засчитывается одно. Хендлеры — `bot/presentation/handlers/tictactoe/`.
